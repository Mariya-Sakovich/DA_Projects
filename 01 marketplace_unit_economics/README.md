# Обзор бизнес-показателей маркетплейса

# Описание проекта
Провести комплексный анализ бизнес-показателей маркетплейса, выявить точки роста и сформулировать рекомендации для развития продукта. Оценить юнит-экономику, пользовательскую воронку и эффективность A/B-теста.

# Ключевые задачи:

Проанализировать динамику ключевых метрик (DAU, MAU, ARPU, LTV, CAC, ROI, Retention).

Построить пользовательскую воронку и определить точки оттока.

Сегментировать метрики по каналам привлечения, регионам, устройствам.

Провести A/B-тест бонуса на первую покупку для TikTok и оценить его эффективность.


# Навыки и инструменты
- pandas
- numpy
- matplotlib
- seaborn
- scipy (Mann-Whitney)
- statsmodels (proportions_ztest)


# Что было сделано

Проанализированы ключевые метрики - DAU, MAU, Stickiness, конверсия, удержание, LTV, CAC, ROI

Построена воронка (регистрация → оплата)

Выполнена сегментация по каналам привлечения, категориям товаров, регионам, устройствам

Оценены результаты A/B-теста (бонус на первую покупку для TikTok).

# Главные инсайты:

Ключевая проблема - отток на этапе оплаты (30-80% по каналам) и после регистрации (>50% не начинают использовать продукт).

TikTok - худший канал (конверсия 6-10%, ROI отрицательный), но на него приходится 80% бюджета с июля.

Лучшие каналы - Affiliate и SEO (ROI 137-377%, CAC низкий).

Бонус на первую покупку для TikTok увеличил конверсию в 7 раз (1.07% → 7.45%), ARPU вырос в 9 раз, качество покупателей не изменилось.
