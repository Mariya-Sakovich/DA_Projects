# Анализ ключевых метрик сервиса доставки еды (Саранск, май-июнь 2021)

# Описание проекта
Проанализировать ключевые бизнес-метрики сервиса доставки еды за период с 1 мая по 30 июня 2021 года для выявления сильных сторон, проблемных зон и формирования стратегических рекомендаций по устойчивому развитию.

# Ключевые задачи
- Рассчитать DAU, Conversion Rate, средний чек, Retention Rate, LTV ресторанов-партнеров

- Провести когортный анализ удержания пользователей

- Выявить топ-рестораны по LTV

- Сформулировать рекомендации по улучшению метрик

# Навыки и инструменты
- PostgreSQL
- когортный анализ 
- визуализация данных

# Что было сделано
Проведен расчет ключевых метрик (DAU, CR, средний чек, RR, LTV) за период май-июнь 2021 года

Выполнен анализ динамики метрик: рост среднего чека (+8,7%) и количества заказов (+5,4%) при падении удержания пользователей

Выделены топ-3 ресторана-партнера по LTV, выявлена их критическая доля в общей выручке сервиса

Сформулированы рекомендации по удержанию пользователей, повышению конверсии, увеличению среднего чека и диверсификации партнерской базы

# Главные инсайты
DAU варьируется от 17 до 85 пользователей: период роста с 23 мая по 11 июня сменяется спадом к концу июня

Conversion Rate стабилен (среднее ~29%), но имеет потенциал для роста выше 30%

Средний чек вырос на 8,7% (135,88 → 147,66 руб.), количество заказов — на 5,4% (2111 → 2225)

Retention Rate критически низкий: 5% на 3-й день с падением до 3% к 5-7 дню в июне

# Общая рекомендация
Проведенный анализ выявляет два основных тренда: позитивное развитие монетизации (рост среднего чека на 8,7% и увеличение заказов на 5,4%) на фоне системных проблем с удержанием пользователей. Приоритетом должна стать стратегия, балансирующая между укреплением лояльности существующих клиентов и диверсификацией партнерской базы для снижения зависимости от ключевых ресторанов.
