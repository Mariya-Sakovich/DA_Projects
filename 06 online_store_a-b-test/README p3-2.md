# Анализ результатов A/B-тестирования интернет-магазина BitMotion Kit

# Описание проекта

Оценить влияние новой версии сайта интернет-магазина BitMotion Kit на конверсию в покупку. Проведен A/B-тест (группа A — старый интерфейс, группа B — новый) со статистической проверкой различий.

# Ключевые задачи:
Проверить корректность проведения теста (отсутствие пересечений, равномерность распределения).

Сравнить конверсию в покупку между группами A и B за первые 7 дней.

Проверить статистическую значимость различий (z-тест пропорций).

# Навыки и инструменты
- pandas 
- matplotlib
- statsmodels

# Что было сделано:
Проверена корректность теста: пересекающиеся пользователи удалены, распределение по устройствам равномерное.

Отобраны события за первые 7 дней после регистрации пользователя.

Рассчитана конверсия в покупку: группа A — 31.73%, группа B — 33.50%.

Проведен односторонний z-тест пропорций (H₁: p_B > p_A).

# Главные инсайты:
Размер выборки достаточен (n_A = 7207, n_B = 7197) для MDE = 3 п.п. при мощности 80%.

Конверсия в группе B выше на 1.77 процентных пункта.

p-value = 0.0203 < α = 0.05 → различие статистически значимо.

Однако фактический прирост (1.77 п.п.) не достиг целевого ориентира в 3 п.п.

# Рекомендация:
Если целевой эффект — ≥3 п.п. → требуется увеличить выборку и продолжить тест.

Если экономически значим любой положительный прирост конверсии → можно внедрять новую версию (эффект статистически доказан).
