# Аналитические отчеты по закупкам для ритейла

# Описание проекта

Подготовка аналитических отчетов о распределении заказов по поставщикам для ритейлера: объемы в шт и USD, доли, средневзвешенные цены, динамика изменений.

# Ключевые задачи

1. Отчет по динамике заказов приоритетных поставщиков (модели, объемы, доли, цены)
2. Отчет по изменению закупочных цен с расчетом отклонений
3. Визуализация и комментарии

# Навыки и инструменты

- **Python** (pandas, matplotlib)
- Объединение таблиц (merge), группировки (groupby)
- Расчет долей, средневзвешенных цен, отклонений
- Визуализация (bar, line, twinx)

# Что было сделано

- Загружены и объединены 4 источника: ассортимент, регионы, цены, курсы валют
- Рассчитаны суммы заказов в USD с учетом курсов
- Построено 2 отчета с группировкой по поставщикам
- Визуализированы: модели/цветомодели, объемы+доли, динамика цен, отклонения

# Главные инсайты

- **Поставщик 4** - ключевой драйвер роста: доля выросла до 37,7%, рост на +20% за счет цены (+20%), объем не изменился
- **Поставщик 1** - основное сокращение: -18,5% к сумме, -3,1 п.п. доли
- **Поставщик 5** - выгодная динамика: рост объема при снижении цены
- Общий рост суммы закупок (+3,9%) при сокращении объема (-1,4%) вызван повышением цен (+5,2%)

# Общая рекомендация

1. Проверить обоснованность роста цен у поставщика 4 (+20%)
2. Выяснить причины сокращения закупок у поставщика 1
3. Расширить сотрудничество с поставщиком 5
4. Снизить зависимость от поставщика 4 (доля 37,6%)
