# Обзор индустрии компьютерных игр. Предобработка и фильтрация данных.

# Описание проекта

Проект посвящен анализу данных сервиса доставки еды для поиска точек роста и повышения эффективности бизнеса. Основная цель — понять поведение пользователей, выявить проблемные этапы воронки, сегментировать клиентов и кластеризовать рестораны для разработки персонализированных маркетинговых стратегий.

# Навыки и инструменты
- pandas
- matplotlib
- missingno
- scikit-learn (KMeans, StandardScaler)

# Общий вывод

Построена воронка пользовательского пути — проанализирована конверсия от авторизации до заказа

Проведена RFM-сегментация — клиенты разделены на группы по давности, частоте и сумме покупок

Выполнена кластеризация ресторанов (K-Means) — выделено 5 кластеров по заказам, среднему чеку и ассортименту

# Ключевые результаты

Конверсия в заказ — 32,6%

Главная проблема — мобильная версия теряет 45% пользователей на подтверждении телефона

56% клиентов совершили 1 заказ на малую/среднюю сумму — потенциал для повторных продаж

5,5% VIP-клиентов приносят основную выручку — нужны эксклюзивные условия

Рестораны Кластера 2 (много заказов, низкий чек) — основной драйвер бизнеса
