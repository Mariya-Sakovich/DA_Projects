# Исследование результатов А/В-теста и поиск инсайтов. Приложение для торговли финансовыми активами.  

# Описание проекта:

Проект посвящен оценке эффективности обновленного онбординга в мобильном приложении для торговли финансовыми активами (SollmaFin). Цель - проверить, поможет ли детальное обучение пользователей финансовым рискам повысить их вовлеченность без снижения конверсии в депозиты.

# Ключевые задачи:

Анализ исторических данных для выявления проблем в пользовательском пути

Оценка результатов A/B-теста (контрольная группа - старый онбординг, тестовая - с обучением рискам)

Статистическая проверка гипотез о влиянии новой фичи на метрики

# Навыки и инструменты: 
- pandas
- numpy
- matplotlib
- missingno
- scipy.stats (ttest_ind)
- statsmodels (proportions_ztest)
- бутстрап numpy.random.choice

# Что было сделано:

Проанализированы исторические данные - выявлены 3 узких места воронки: после онбординга (-19%), после депозита (-44%), после покупки активов (-65%)

Проведен A/B-тест на 9415 новых пользователях (2-15 июня 2025)

Проверены 4 метрики с помощью t-test и z-test пропорций

Выполнен бутстрап для анализа изменений распределения депозитов

# Главные инсайты:

Новый онбординг отсеивает осторожных пользователей (25-й перцентиль упал с 95 до 48), но привлекает крупных инвесторов (75-й перцентиль вырос с 159 до 180)

Конверсия во второй депозит среди покупателей высокорисковых активов выросла с 28% до 46% (+18 п.п., статистически значимо)

Гипотеза риска не подтвердилась - барьерная метрика не упала значимо

Гипотеза роста подтвердилась частично - удержание выросло, но ARPU - нет

# Рекомендация:

Внедрять новую версию онбординга - она улучшает качество аудитории и долгосрочное удержание, несмотря на отсутствие немедленного роста ARPU. Рекомендуется оптимизировать онбординг для снижения отсева на входе (-8 п.п.).
