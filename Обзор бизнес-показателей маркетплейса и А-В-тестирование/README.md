# Обзор бизнес-показателей маркетплейса

# Описание проекта
Анализ бизнес-показателей маркетплейса. Цель — выявить точки роста, оценить эффективность каналов привлечения, проанализировать юнит-экономику и предложить гипотезы для улучшения продукта.

# Ключевые задачи:

Анализ ключевых метрик (DAU/MAU, retention, конверсия, ARPU, ARPPU, AOV, LTV, CAC, ROI)

Оценка юнит-экономики и окупаемости вложений

Сегментация пользователей по каналам привлечения, категориям товаров, регионам, устройствам

Дизайн и анализ A/B-теста для канала TikTok



# Навыки и инструменты
- pandas
- numpy
- matplotlib
- seaborn
- scipy (Mann-Whitney)
- statsmodels (proportions_ztest)


# Что было сделано

Проведен первичный анализ и предобработка 4 датасетов (заказы, пользователи, события, маркетинговые траты)

Проанализированы ключевые метрики — DAU, MAU, Stickiness, конверсия, удержание, LTV, CAC, ROI

Выполнена сегментация по каналам привлечения, категориям товаров, регионам, устройствам

Проведен A/B-тест для пользователей TikTok (бонус на первую покупку)

# Главные инсайты:

TikTok — самый неэффективный канал: 80% бюджета, но 6-10% конверсии в заказ, отрицательный ROI (против 137-377% у Affiliate/SEO)

Системная проблема с оплатой: 30-80% пользователей не оплачивают оформленные заказы

Падение метрик во втором полугодии — общий тренд для всех сегментов

Affiliate и SEO — недооцененные каналы с высокой окупаемостью

Бонус на первую покупку для TikTok показал эффективность: конверсия выросла с 1% до 7,5% (+599%), ARPU вырос в 9 раз, при сохранении качества покупателей (ARPPU и AOV не изменились)

# Ключевые гипотезы для развития:

Оптимизация процесса оплаты (+20-30% конверсии)

Перераспределение бюджета с TikTok на Affiliate/SEO (+100% ROI)

Внедрение онбординга для активации пользователей (+30% активных)

Персонализированные рекомендации и программа лояльности
