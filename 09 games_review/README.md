# Обзор индустрии компьютерных игр

# Описание проекта:

Изучить развитие игровой индустрии с 2000 по 2013 год на основе данных о продажах игр, жанрах, платформах и оценках пользователей/критиков для выявления ключевых трендов.

# Ключевые задачи:
Предобработать данные (исправить типы, обработать пропуски и дубликаты).

Отфильтровать данные за 2000–2013 годы.

Категоризировать игры по оценкам пользователей и критиков (низкая/средняя/высокая).

Выделить ТОП-7 платформ по количеству выпущенных игр.


# Навыки и инструменты:
- pandas
- matplotlib


# Что было сделано: 

Проведена обработка исходных данных - исправлены типы данных, обработаны пропуски и дубликаты

Сделан срез по годам (с 2000 по 2013 включительно).  Добавлены категории оценок пользователей и критиков. 

Выделены ТОП-7 платформ.

# Главные инсайты:
Пользователи чаще критиков ставят как высокие, так и низкие оценки. Доля средних оценок у критиков выше.

Высокая оценка среди пользователей встречается в 2 раза реже средней, среди критиков — в 3 раза реже.

ТОП-7 платформ: PS2 (16.65% игр), Nintendo DS (16.59%), PS3, Wii, PSP, X360, GBA (от 6.35% до 9.98%).
