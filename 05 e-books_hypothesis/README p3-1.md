# Проверка гипотезы в Python и составление аналитической записки. Яндекс.Книги

# Описание проекта

Проверить гипотезу о том, что пользователи из Санкт-Петербурга проводят больше времени в сервисе Яндекс.Книги (чтение/прослушивание), чем пользователи из Москвы, на основе данных об активности в часах.

# Ключевые задачи

Загрузить и предобработать данные (удалить дубликаты пользователей, посещавших оба города).

Выбрать корректный статистический тест для проверки гипотезы.

Сравнить среднюю активность пользователей Москвы и Санкт-Петербурга.

Сформулировать выводы и подготовить аналитическую записку.

# Навыки и инструменты
- pandas
- matplotlib
- scipy (Mann-Whitneyu)

# Что было сделано
Загружен датасет (8784 пользователя). 

Обнаружены и удалены пользователи, которые заходили в приложение в обоих городах (нарушение независимости выборок). 

Визуализированы распределения активности (логарифмическая шкала). 

Проведен тест Манна-Уитни (односторонний, H₁: активность в СПб выше).

# Главные инсайты:
Распределения активности в обоих городах не являются нормальными (сильный перекос в сторону малых значений).

Средняя активность в СПб (5.80 ч) выше, чем в Москве (5.28 ч).

p-value = 0.089 > α = 0.05 → разница статистически не значима.

Наличие выбросов и разный размер выборок (СПб - 2550, Москва - 6234) могли повлиять на мощность теста.

# Рекомендация:
Гипотеза не подтверждена. Для окончательных выводов рекомендуется увеличить объем данных или провести анализ с учетом/исключением выбросов. Более высокое среднее в СПб может объясняться единичными аномально активными пользователями.
