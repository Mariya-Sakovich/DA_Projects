# Поиск инсайтов и точек роста для сервиса доставки еды

# Описание проекта

Выявить точки роста для сервиса доставки еды: проанализировать поведение пользователей (воронка), сегментировать клиентов по лояльности (RFM) и кластеризовать рестораны для персонализации маркетинговых стратегий.

# Ключевые задачи 
Построить воронку пользовательского пути и определить этапы с наибольшими потерями.

Сегментировать покупателей по Recency, Frequency, Monetary (RFM).

Кластеризовать рестораны методом K-Means по количеству заказов, среднему чеку и ассортименту.

# Навыки и инструменты
- pandas
- matplotlib
- missingno
- scikit-learn (KMeans, StandardScaler)
- RFM-сегментация

# Что было сделано:

Построена воронка из 7 шагов (authorization → order). Конверсия в заказ — 32.6%.

Сравнены воронки для Mobile и Desktop.

Проведена RFM-сегментация всех покупателей.

Выполнена K-Means кластеризация 21 ресторана по 3 параметрам, выбрано 5 кластеров.

# Главные инсайты:
Ключевая проблема — подтверждение телефона на мобильной версии: теряется 45% пользователей (на десктопе — 10%).

В мобильной версии 17% не доходят даже до главной страницы (возможны технические сбои или некачественный трафик).

RFM: 56.5% пользователей совершили 1 заказ на малую/среднюю сумму (сегменты 212,211,111,112,311) — массовый сегмент с потенциалом повторных заказов. Только 5.5% — VIP-клиенты (333,332,323,233,133).

Кластеры ресторанов: 
- Кластер 2 — много заказов, низкий чек, широкий ассортимент (основной поток)

- Кластер 3 — мало заказов, высокий чек, узкий ассортимент (премиум, потенциал расширения меню)

# Рекомендация:
Мобильная версия — срочно исправить этап подтверждения телефона (упростить интерфейс, проверить ошибки).

RFM-сегменты: VIP-клиентам (5.5%) — эксклюзивные предложения; массовому сегменту (56.5%) — скидки и бонусы за второй заказ.

Рестораны: кластеру 3 расширить ассортимент (сейчас 2–3 блюда), кластеру 2 — поддерживать; кластер 4 (низкий чек, мало заказов) — пересмотреть либо заменить.
