
# Дашборд о конференциях TED

# Описание проекта

Дашборд для организации конференции TED на основе данных о прошлых мероприятиях. Помогает выбрать темы, спикеров и спланировать расписание.

# Ключевые задачи

Проанализировать датасет: количество конференций, выступлений, выступающих, тегов.

Детализировать данные по странам и конференциям (длительность выступлений, просмотры, аплодисменты).

Составить топ‑10 смешных выступлений и топ‑20 популярных тегов.

Выявить сферы деятельности спикеров с наибольшим числом аплодисментов.

Создать дашборд с фильтрами.

# Навыки и инструменты

* SQL 
* Yandex Datalens

# Что было сделано

Собран датасет (конференции, выступления, спикеры).

Построены визуализации.

Разработан дашборд в Yandex Datalens с фильтрами по темам, странам, дате, конференциям.

# Главные инсайты

* Всего: 327 конференций, 3377 выступлений, 2943 выступающих, 80 тегов.
* Средняя длительность выступления: 12-14 мин.
* Макс. просмотров у выступления: 72,2 млн.
* Топ‑3 страны по числу спикеров: США (1668), Канада (560), Великобритания (271).
* Популярные теги: наука, технологии, культура.
* Больше всего аплодисментов - у спикеров следующих профессий: педагог, "пионер" автономных систем, активист.
