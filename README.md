#### 4. [Проверка гипотезы в Python и составление аналитической записки](<https://github.com/Mariya-Sakovich/Practicum_projects/tree/main/p3%20%D0%9F%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D0%BA%D0%B0%20%D0%B3%D0%B8%D0%BF%D0%BE%D1%82%D0%B5%D0%B7%D1%8B%20%D0%B2%20Python>)
***Описание:** Команда сервиса Яндекс Книги изучила данные, полученные при анализе LTV, и выдвинула гипотезу. Она заключается в том, что пользователи, которые приносят больший LTV, являются более лояльными, а значит, проводят в среднем больше времени за чтением и прослушиванием книг в приложении. Команда предлагает сравнить пользователей из Санкт-Петербурга и Москвы, ведь при расчётах среднего LTV было определено, что эта метрика у петербуржцев выше.*
*   **Стек:** Python, Pandas, Matplotlib, Scipy.stats.mannwhitneyu
